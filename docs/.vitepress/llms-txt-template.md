# QuestPDF

> QuestPDF is a C# library for generating PDF documents such as invoices, reports and data exports. Documents are written in C# with a fluent API, not in HTML.
> You compose layouts from elements like text, images, SVG, tables and grids, and the layout engine splits the content across pages, including headers, footers and page numbers. Barcodes are added by integrating ZXing.Net.
> Output can comply with PDF/A, PDF/UA and ZUGFeRD/Factur-X. Existing PDFs can be merged, overlaid, encrypted and given attachments. Runs on Windows, Linux and macOS, including Docker and cloud hosting. The Companion App previews documents with hot reload.

Install with `dotnet add package QuestPDF`. Start with [Quick start](https://www.questpdf.com/quick-start.md), then the [In-Depth Invoice Tutorial](https://www.questpdf.com/invoice-tutorial.md).
